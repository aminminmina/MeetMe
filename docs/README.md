# Общий отчёт по программной инженерии: проект MeetMe

## 1. Цель проекта и назначение системы
Разрабатываемая система **MeetMe** предназначена для быстрого совместного выбора места или активности для проведения досуга двумя пользователями или группой друзей[cite: 1, 2, 3]. Основной целью разработки является сокращение времени согласования совместного досуга и упрощение принятия общего решения с учетом местоположения, бюджета и предпочтений участников[cite: 1, 2, 3].

- **Тип приложения:** Веб-приложение (работа через стандартный браузер без установки приложений)[cite: 1, 2, 3].
- **Целевая аудитория:** Пары или группы друзей (основной размер группы — от 3 до 6 человек)[cite: 1, 2, 3].

---

## 2. Роли пользователей в системе
* **Организатор комнаты** — создает комнату, приглашает участников, задает общие параметры (бюджет, атмосфера), оценивает варианты и просматривает итог[cite: 1, 2, 3].
* **Участник комнаты** — присоединяется по коду/ссылке, указывает точку старта и свои предпочтения, участвует в оценке карточек с помощью свайпов[cite: 1, 2, 3].

---

## 3. Перечень требований к системе

### Функциональные требования (ФТ):
* **Создание комнаты и подготовка:**
  - Создание отдельной комнаты с уникальным кодом[cite: 1, 2, 3].
  - Подключение участников по приглашению[cite: 1, 2, 3].
  - Указание точки старта (адрес или геолокация)[cite: 1, 2, 3].
  - Настройка бюджета (учет минимального бюджета среди участников)[cite: 1, 2, 3].
  - Настройка атмосферы и выбор категорий досуга[cite: 1, 2, 3].
  - Определение географически удобной зоны встречи[cite: 1, 2, 3].
* **Совместный выбор:**
  - Отображение карточек мест и активностей[cite: 1, 2, 3].
  - Оценка вариантов с помощью свайпов (влево/вправо)[cite: 1, 2, 3].
  - Автоматическое определение общего совпадения (положительно оценен всеми)[cite: 1, 2, 3].
  - Функция «рулетка» для случайного выбора при отсутствии общего совпадения[cite: 1, 2, 3].

### Нефункциональные требования:
* Понятность интерфейса и кроссплатформенная адаптивность (ПК, планшеты, смартфоны)[cite: 1, 2, 3].
* Безопасность и конфиденциальность данных о местоположении пользователей[cite: 1, 2, 3].
