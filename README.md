# Веб-приложение для планирования досуга MeetMe

## Назначение
MeetMe — веб-приложение для быстрого совместного выбора места или активности для пары или группы друзей (от 3 до 6 человек) путем согласования геолокации, бюджета и свайп-оценки вариантов[cite: 1, 2].
